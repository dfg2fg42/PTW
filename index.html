🔒 관리자 모드

⚙️ 부서별 자동 분류 설정

수동 지정 → 우선 분류 → 일반 키워드 규칙 → 공동 표시 순서로 적용합니다. 저장하면 현재 목록에 즉시 반영되고 이 브라우저에 유지됩니다. 개별 수동 지정은 유지되며, 사용자 설정은 다른 PC에 자동 공유되지 않습니다.

우선 분류 기준

  1. 위의 연료·가스 취급 작업을 먼저 검사합니다.
  2. 탈황폐수처리 작업위치는 FGD, ESP/전기집진기 설비는 EP를 우선합니다.
  3. SBO의 ‘작업명’ 규칙을 먼저 검사합니다. 기본값은 전동기·항온항습기·Exciter Room입니다.
  4. 실제 작업위치·등록 설비가 명확하면 해당 보직을 적용합니다.
  5. 나머지는 아래 일반 키워드 규칙을 순서대로 검사합니다.

한 작업을 여러 보직에 함께 표시

1·2호기 공동 보일러/터빈 작업은 양쪽 보직에 표시합니다. 카드별로 집계하되 전체 취합의 건수·인원은 중복 계산하지 않습니다. 수동 지정 작업에는 공동 표시를 추가하지 않습니다.

호기 판별 기준 수정

작업명에 명시된 호기를 먼저 확인합니다. 작업위치에 명확한 단일 호기가 있으면 그 위치를 우선하며, 단서가 없으면 운전부서로 판단합니다. Light Oil 충유의 양쪽 터빈 공동 표시는 위 설정을 따릅니다.

일반 키워드 규칙

우선 분류에 해당하지 않는 작업은 위에서부터 처음 일치한 규칙을 적용합니다. 키워드는 쉼표 또는 줄바꿈으로 구분하며 하나라도 포함되면 일치합니다. 영문 대소문자·공백·하이픈 차이는 무시합니다. 일치 규칙이 없으면 기타로 분류합니다.

📑 오늘~내일 · 전체 건수 조회 북마크

북마크는 수집창만 엽니다. ‘오늘~내일 조회·동기화’ 버튼을 누르면 오늘부터 내일까지 검색하고 수집을 시작합니다. 시작 후 두 화면을 켜 두면 갱신 완료 후 30분마다 다시 조회합니다. 날짜가 바뀌면 새 오늘~내일 범위로 갱신하며, 실패하면 30초 후 재검색합니다. 최근 조회와 전송 시간을 따로 표시하고 변경이 없으면 다시 전송하지 않습니다. 전체 페이지를 모아 총건수도 확인합니다. 다른 기간은 원본의 작업허가 기간을 바꾼 뒤 ‘선택 기간 조회·동기화’를 누르세요. 선택한 기간은 자동 조회에도 유지됩니다. 수집창을 닫으면 자동 갱신이 중지되며, 원본 페이지를 새로고침했다면 북마크를 열고 버튼을 다시 눌러 시작하세요.

📑 오늘~내일 / 전체 건수 북마크
  1. 위 버튼을 북마크바로 드래그하거나, 코드를 복사해 기존 북마크의 URL에 붙여넣으세요.
  2. 사내 안전작업허가서 목록을 열고 등록한 북마크를 누르세요.
  3. 수집창의 ‘오늘~내일 조회·동기화’를 눌러 시작하세요. 이후 두 화면을 켜 두면 30분마다 다시 검색해 추가 작업과 결재 변경을 반영합니다.
  4. 기존 코드를 교체했다면 원본 페이지를 새로고침한 뒤 실행하세요.
